# Lab 2 — 定时器时间基准 + PWM 方波

## 目标

用 TIM2_CH1 在 PA0 输出方波：先 1 kHz 验证，再 250 kHz（项目目标）。

## 前置知识

- 定时器时基：PSC（预分频）、ARR（自动重载）、CNT（计数器）
- PWM 模式 1 / 模式 2 的区别
- 复用功能（AF）引脚——见 `docs/学习路线图.md` 模块 2

## 任务清单

| 编号 | 任务 |
|---|---|
| 2-1a | 使能 TIM2 时钟（**APB1**） |
| 2-1b | ★ **使能 GPIOA 时钟（APB2）** —— 漏了它 PA0 不会有任何波形 |
| 2-2 | PA0 配成**复用推挽**输出 |
| 2-3 | 设置 PSC / ARR |
| 2-4 | 通道 1 配 PWM 模式 1 + OC1PE |
| 2-5 | 设置 CCR1 |
| 2-6 | 使能 CC1E（`CCER`） |
| 2-7 | 使能 CEN（`CR1`） |

## 寄存器速查

| 寄存器 | 位域 | 含义 |
|---|---|---|
| `RCC->APB1ENR` | TIM2EN (bit0) | TIM2 时钟 |
| `RCC->APB2ENR` | **IOPAEN (bit2)** | **GPIOA 时钟** ★ 最容易漏 |
| `TIM2->CCMR1` | OC1M[2:0]=110 | PWM 模式 1 |
| `TIM2->CCMR1` | OC1PE (bit3) | 输出比较预装载 |
| `TIM2->CCER` | CC1E (bit0) | 通道 1 输出使能 |
| `TIM2->CR1` | CEN (bit0) | 计数器使能 |
| `GPIOA->CRL` | PA0 四位 CNF=10 | 复用推挽 |

## 核心公式

```
f_cnt = 72MHz / (PSC + 1)
f_out = f_cnt / (ARR + 1)
(PSC+1) × (ARR+1) = 72MHz / f_out
高电平时间 = CCR1 / f_cnt        (PWM 模式 1)
```

**250 kHz**：需要 (PSC+1)(ARR+1)=288
- 若 PSC=0 → ARR=287，f_cnt=72MHz，1 tick≈13.9ns（分辨率最高）
- 50% 占空比 → CCR1 = 144
- 这个配置正好对应图 6 的 4µs 周期（288 tick）

**1 kHz**：需要 (PSC+1)(ARR+1)=72000
- ARR 只有 16 位（≤65535），所以不能全给 ARR
- 取 PSC=71（72 分频）→ f_cnt=1MHz → ARR=999 → 1kHz
- 50% → CCR1 = 500

## 常见坑

- **时钟写成了 APB2** → 定时器不工作（TIM2/3/4 在 APB1，TIM1/8 在 APB2）
- **PA0 用了普通推挽** → 没有波形，因为引脚没交给定时器控制
- **忘了 CEN** → 计数器不跑，什么都不动
- **ARR 超过 65535** → 溢出/异常，低频要配合 PSC 分频
- **改 CCR 不生效？** → 检查 OC1PE 与"更新事件"时机

## 关键领悟

> 定时器把"时间"变成了"计数值"。只要算对 PSC/ARR，硬件就精确地替你数数——
> **CPU 不用参与**。这是后面所有时序能力的基础。
