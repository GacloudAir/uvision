# Lab 3 — 输出比较"翻转"模式

## 目标

用 OC Toggle 模式让 PA0 输出 250 kHz 方波，并理解"让引脚在指定时刻翻转"这一核心能力。

## 前置知识

- 输出比较通道、CCR 的作用（Lab2 已接触）
- 触发与翻转的区别

## Toggle 与 PWM 对比（本 Lab 的灵魂）

| 维度 | PWM 模式 | Toggle 模式 |
|---|---|---|
| OC1M 值 | 110 | **011** |
| 一圈内动作 | 置位 + 复位（两次） | **翻转（一次）** |
| 输出频率 | `f_cnt/(ARR+1)` | **`f_cnt/(2×(ARR+1))`** |
| CCR 决定 | 占空比 | **翻转时刻（相位）** |
| 适合场景 | 固定占空比方波 | **精确布点/指定时刻翻转** |

> 注意"输出频率减半"——因为 Toggle 一圈只翻一次，要两圈才凑出一个完整方波。

## 参考答案对照（算完再看）

<details>
<summary>点开查看（请务必先自己算！）</summary>

**250 kHz、50% 方波（Toggle）**
- `f_out = f_cnt / (2(ARR+1))`
- 取 PSC=0 → f_cnt=72MHz → `2(ARR+1)=288` → **ARR=143**
- 50% 占空比 → 翻转点在一圈的正中间 → **CCR1 = 72**

对比 Lab2：同样 250kHz 输出，PWM 用 ARR=287，Toggle 用 ARR=143 加 CCR=72。
**参数不同、原理不同，但都能出波形**——这就是要你体会的差别。

</details>

## 关于 Q3（如何"只翻转一次"）的思路参考

<details>
<summary>点开查看</summary>

1. **单脉冲模式（OPM）+ 中断**：翻转后停止，或下一次再启动
2. **中断里动态改 CCR**：在 ISR 中把下一次要翻转的时刻写进 CCR，让引脚按计划"跳"
3. **用 PWM 模式的不同相位组合**：多个通道各出半个脉冲拼起来
4. **不用硬件翻转，直接在定时器中断里写 GPIO**（简单直接，但时刻精度受中断延迟影响）

这些思路都会在 Lab 4 里用到其中一种或几种。想清楚它们的取舍，是你自己的收获。

</details>

## 常见坑

- **按 Lab2 的思路算 ARR** → 频率会差一倍（别忘了"一圈只翻一次"）
- **CCR1 设成 0 或 ≥ARR** → 翻转时机异常，先取中间值
- **又忘了 CC1E 或 CEN** → 没输出

## 关键领悟

> Toggle 模式把"引脚电平变化"和"计数器到达某个值"绑定在一起。
> 既然一个定时器有 4 个通道、4 个 CCR，那就可以让 4 个引脚
> **各自在 4 个不同的时刻翻转**——这正是 Lab 4 要干的事。
