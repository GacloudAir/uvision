# Lab 1 — GPIO 输出与"上电安全态"

## 目标

把 PA0–PA3 配成推挽输出并默认拉低，用 PC13 的 LED 做心跳，建立"上电保持关断"的安全意识。

## 前置知识

- GPIO 的 8 种工作模式（推挽/开漏/上拉/下拉/复用/模拟）——见 `docs/学习路线图.md` 模块 1
- 位操作：`|=`、`&=~`、`<<`、`~`

## 寄存器速查

| 寄存器 | 作用 |
|---|---|
| `RCC->APB2ENR` | bit2=IOPAEN, bit4=IOPCEN |
| `GPIOA->CRL` | PA0–PA7，每引脚 4 位 |
| `GPIOC->CRH` | PC8–PC15，每引脚 4 位 |
| `GPIOx->BSRR` | 低 16 位=置位，高 16 位=复位 |
| `GPIOx->ODR` | 输出数据寄存器 |

**4 位含义**：`CNF[1:0]` `MODE[1:0]`
- 推挽输出：CNF=00
- 输出速度：MODE=11 表示 50MHz
- 合起来一个引脚的 4 位 = `0b0011` = 0x3

## 思考题（务必先想再看答案）

1. **PC13 属于 CRL 还是 CRH？** → 自己判断：CRL 管 Px0–Px7，CRH 管 Px8–Px15。
2. **忘了开 GPIOA 时钟会怎样？** → 想想"时钟是外设的电源开关"这句话。
3. **为什么先清零再写 CRL 位域？** → 提示：如果原来是复用功能，直接 `|=` 会留下脏位。
4. **BSRR vs ODR？** → BSRR 是原子的（一条指令完成置位/复位），ODR 是"读-改-写"，在多处并发改同一端口时可能出错。

## 常见坑

- **忘了开时钟** → 引脚毫无反应（最常见！）
- **PC13 配到 CRL** → LED 不亮，实际改的是 PC0–PC7 的配置
- **忙等延时被优化掉** → 循环变量没加 `volatile`
- **用 ODR 整端口赋值** → 把其他 PA 引脚的状态也冲掉了，建议用 BSRR
