# Lab 6 — 串口参数下发

## 目标

用 USART1（PA9/PA10）与上位机通信，收到命令后改变发射频率（50–300 kHz）。

## ★ 本工程标准参数（Lab4–6 统一）

| 量 | 取值 |
|---|---|
| f_cnt / PSC | 72 MHz / **0**（1 tick = 13.9 ns） |
| ARR（250 kHz） | **287**（288 tick） |
| 改频率 | **只改 ARR**（并把各 CCR 按比例改），f_cnt 固定 |

## 前置知识

- USART 波特率原理（BRR = 分频值）
- 总线与时钟：USART1 在 **APB2**、USART2/3 在 APB1
- 简单协议与状态机——见 `docs/学习路线图.md` 模块 8

## 寄存器速查

| 寄存器 | 关键位 | 说明 |
|---|---|---|
| `RCC->APB2ENR` | USART1EN (bit14) | USART1 时钟 |
| `USART1->BRR` | — | 波特率分频 |
| `USART1->CR1` | UE(13) TE(3) RE(2) RXNEIE(5) | 使能与中断 |
| `USART1->SR` | RXNE(5) TXE(7) | 收发状态 |
| `USART1->DR` | — | 读=收，写=发 |

## 换算助手

**波特率 115200 @ 72MHz**：
```
72,000,000 / 115200 = 625
625 = 0x271   →  BRR = 0x0271（当小数部分为 0 时）
```
（若除不尽，BRR = 整数部分<<4 | 小数部分×16 四舍五入）

**频率 → 时基**（本工程：**PSC=0 固定，改 ARR**）：

```
f_cnt 固定 72MHz（PSC=0）→   ARR = 72MHz / f_out - 1
各 CCR 按比例改：OE = (ARR+1)/2，PULSE = (ARR+1)/4，依此类推

250kHz -> ARR=287    200kHz -> ARR=359    300kHz -> ARR=239
150kHz -> ARR=479    100kHz -> ARR=719     50kHz -> ARR=1439
```

## 建议协议

```
帧：0xAA | CMD | D_H | D_L | SUM
  CMD=0x01      设置频率（kHz）
  D_H,D_L       频率高/低字节
  SUM           前四字节累加和低 8 位
回复：0xAA | 0x81 | 0x00    （成功）
```

## 验证方法

| 验证点 | 方法 | 期望 |
|---|---|---|
| 串口连通 | 上位机发任意字节 | 能收到回复 |
| 改频率 | 发 0xAA 01 00 FA 校验 | 示波器上频率变为 250kHz |
| 非法数据 | 发越界频率 | 被拒绝，不改变输出 |
| 帧错位 | 故意发错校验 | 丢弃，不误动作 |

## 常见坑

- **时钟写到 APB1** → USART1 完全不工作
- **BRR 算错** → 乱码（波特率不匹配）
- **PA9 没配复用** → 发不出数据
- **中断里读 DR 却忘了清标志** → 反复中断
- **改 ARR 时不同步** → 输出出现毛刺，考虑用预装载 + 更新事件

> 到这一步，你的时序控制器已经具备"可配置"能力：
