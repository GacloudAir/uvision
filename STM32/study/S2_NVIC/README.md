# S2 — 中断与 NVIC

## 回答你在 Lab4 留下的三个疑问

| 疑问 | 答案 |
|---|---|
| 为什么边沿整体晚 ~0.3µs？ | 硬件响应(≈12 周期)+入栈+取向量 ≈0.15~0.2µs，再加 ISR 前置。但**每次都一样晚**，所以相对关系仍正确 |
| 两个中断同时来谁先？ | 抢占优先级高的先；相同则看子优先级（只排队，不互相打断） |
| 能插队吗？ | 抢占优先级更高的可以**打断**正在跑的 ISR |

## 优先级分组（F103 有 4 位优先级）

```c
NVIC_SetPriorityGrouping(3);   /* 抢占位数 = 7 − PRIGROUP → 4 位抢占、0 位子优先级 */
```

| PRIGROUP | 抢占位数 | 子优先级位数 |
|---|---|---|
| 7 | 0 | 4 |
| 5 | 2 | 2 |
| 4 | 3 | 1 |
| **3** | **4** | **0** |

> 数值越小优先级越高（0 最高）。`NVIC_SetPriority(IRQn, x)` 里的 `x` 就是抢占级。

## 实验设计

| 中断 | 周期 | 优先级 | ISR 做什么 |
|---|---|---|---|
| TIM3 更新 | 500 ms | **5（低）** | 进 ISR 拉高 PA1 → 忙等 300ms → 拉低 PA1 |
| EXTI0（PA0 按键下降沿） | 随时 | **0（高）** | 点亮 PC13 的 LED |

**观察**：
1. 只跑 TIM3 → 示波器 PA1 上是 300ms 宽、500ms 一周期的脉冲
2. **在 TIM3 长中断期间按按键** → LED 立即亮 = 抢占成功
3. 把两者优先级对调再试 → LED 要等 TIM3 跑完才亮

## ⚠ 最容易漏的一步

配 EXTI 必须开 **AFIO 时钟**（`RCC->APB2ENR |= (1U << 0);`）—— 这正是 S1 讲的"外设时钟门控"的一个实例，漏了就毫无反应。

| 寄存器 | 作用 |
|---|---|
| `AFIO->EXTICR[0]` bit3:0 | 选 EXTI0 来自哪个端口（0000=PA，0001=PB…） |
| `EXTI->IMR` | 中断屏蔽（1=开） |
| `EXTI->FTSR` / `RTSR` | 下降沿 / 上升沿触发 |
| `EXTI->PR` | 挂起标志，**写 1 清除** |

## 按键接法（不用外接电阻）

PA0 配成**输入+上拉**（CNF=10, MODE=00 → `0x8`），并**把 ODR 的 bit0 写 1** 使能上拉；
按键另一端接地 → 按下产生下降沿。
