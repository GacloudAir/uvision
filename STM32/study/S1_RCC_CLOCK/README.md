# S1 — 时钟树与复位

## 为什么做这个

你在 Lab1–4 里反复踩的坑，根都在时钟树：
- "忘开时钟，引脚毫无反应"
- "频率算出来和实际对不上"

做完这个模块，你应该能自己回答：SYSCLK 从哪来？HCLK/PCLK1/PCLK2 各多少？
**以及最关键的一条：TIM2 的计数时钟到底是多少？**

## ★ 核心结论（先记住，再用实验验证）

```
HSE 8MHz ─▶ PLL ×9 ─▶ SYSCLK 72MHz
   │
   ├─ HPRE=1  ─▶ HCLK  = 72MHz
   ├─ PPRE2=1 ─▶ PCLK2 = 72MHz
   └─ PPRE1=2 ─▶ PCLK1 = 36MHz
                    │
                    ★ 挂在 APB1 的定时器（TIM2/3/4）时钟 = PCLK1 × 2 = 72MHz
```

> 这一条解释了：**为什么你所有代码里 `PSC=0` 时 TIM2 就是 72MHz**。
> 如果哪天把 PPRE1 改成不分频，定时器时钟就变成 72MHz（APB1 超规格，仅作思想实验）。

## 关键寄存器速查

| 寄存器 | 位域 | 含义 |
|---|---|---|
| `RCC->CR` | HSIRDY / HSERDY / PLLRDY | 时钟源是否稳定 |
| `RCC->CFGR` | SWS[3:2] | 当前系统时钟源：00=HSI 01=HSE 10=PLL |
| `RCC->CFGR` | HPRE[7:4] | AHB 预分频 |
| `RCC->CFGR` | PPRE1[10:8] | APB1 预分频 |
| `RCC->CFGR` | PPRE2[13:11] | APB2 预分频 |
| `RCC->APB1ENR` / `APB2ENR` | — | 外设时钟门控 |

⚠ **分频编码不是"数值=分频倍数"**，要查表：

| AHB (HPRE) | 值 | | APB (PPRE) | 值 |
|---|---|---|---|---|
| 0xxx | 1 分频 | | 0xx | 1 分频 |
| 1000 | 2 | | 100 | 2 |
| 1001 | 4 | | 101 | 4 |
| 1010 | 8 | | 110 | 8 |
| 1011 | 16 | | 111 | 16 |
| 1100~1111 | 64/128/256/512 | | | |

## T2 的两组答案（自己先算，再对照）

⚠ **订正**：下面这张表第一版漏了一个关键点 —— **中断里翻转一次只产生半个周期**。
一次"亮+灭"需要**两次**更新中断，所以 `f_方波 = f_更新 / 2`。

| 假设 | 要 1Hz 方波 → 更新率需 2Hz | 一种可行分解 |
|---|---|---|
| f_cnt = 36 MHz | (PSC+1)×(ARR+1) = 18,000,000 | PSC=2999, ARR=5999 （3000×6000） |
| **f_cnt = 72 MHz（正确）** | (PSC+1)×(ARR+1) = 36,000,000 | **PSC=5999, ARR=5999** （6000×6000） |

**10 秒验收（改 `USE_GROUP_B` 切换）**：

| 下载哪组 | 真实 f_cnt=72MHz 时的更新率 | 闪灯频率 | 10 秒闪几次 |
|---|---|---|---|
| 乙组 PSC=5999 ARR=5999 | 2 Hz | 1 Hz | **10 次** ✅ 与预期一致 |
| 甲组 PSC=2999 ARR=5999 | 4 Hz | 2 Hz | **20 次** ❌ 快了一倍 |

> 看到"比预期快一倍"，就实锤了 TIM2 的时钟是 PCLK1×2 = 72MHz 而不是 36MHz。

## PC13 注意

**PC13 不是 TIM2 的通道引脚**，不能用 PWM 直接驱动 → 用"更新中断 + ISR 里翻转 PC13"。
（另外 PC13 驱动能力弱，只能点亮小电流 LED，蓝板上已有限流电阻。）

⚠ 因此 CRH 里要配【通用推挽】`0x2`（2MHz），**不能配 `0xB`（复用推挽）**：
`0xB` 的含义是"这个脚交给片上外设驱动"，而 PC13 上根本没有 TIM2 的复用通道，
结果就是引脚被交给一个不存在的东西，你再怎么写 ODR 都没反应 —— 和"忘开时钟"是同一种现象。
