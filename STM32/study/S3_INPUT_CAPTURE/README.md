# S3 — 输入捕获：用 STM32 测自己产生的波形

## 意义

前面几个 Lab 一直在"产生"波形，靠示波器肉眼比对。
这里换个方向：**用 STM32 把信号量出来** —— 形成闭环（产生 → 测量 → 验证），
也是以后调试任何时序的通用手段。

## 原理（一句话）

边沿到来时，把 `CNT` 的当前值**锁存**进 `CCRx`：

```
信号 ───╱‾‾‾‾‾╲_____╱‾‾‾‾‾╲_____
        ↑          ↑
      捕获1       捕获2
      CNT=t1      CNT=t2

周期 = (t2 − t1) 个 tick（注意回绕，要取模）
频率 = f_cnt / 周期(tick)
```

本实验理论值：**288 tick → 250 kHz**（f_cnt = 72MHz）。

## 接线

| 引脚 | 作用 |
|---|---|
| **PA1** (TIM2_CH2) | 我们自己产生的被测波形（250kHz, 50%） |
| **PA6** (TIM3_CH1) | 捕获输入 |
| GND | **必须共地** |

> 用一根杜邦线把 PA1 接到 PA6 即可。示波器可以同时看 PA1 与 PA6 对比。

## 任务清单

| 编号 | 任务 |
|---|---|
| T1 | TIM2_CH2 (PA1) 产生 250kHz/50%：`PSC=0, ARR=287, CCR2=144`，PWM1 |
| T2 | TIM3_CH1 (PA6) 输入捕获：`CC1S=01`、`CC1E=1`、`CC1P=0`、`CC1IE=1` |
| T3 | ISR 里取两次上升沿的 CNT 差 → 周期 |
| T4 | 主循环判断周期是否 ≈288（±3）→ 点亮 PC13 的 LED |

> **T4 就是你的自动验收测试**：线接对、参数对，灯就亮；否则灭。

## 寄存器速查

| 寄存器 | 位 | 说明 |
|---|---|---|
| `TIM3->CCMR1` | CC1S[1:0] | 01 = 输入，IC1 映射到 TI1 |
| `TIM3->CCMR1` | IC1PSC[3:2] | 输入预分频（1/2/4/8 次事件才捕获一次） |
| `TIM3->CCMR1` | IC1F[7:4] | 输入滤波（抗毛刺，测 250kHz 可先设 0） |
| `TIM3->CCER` | CC1E(0) / CC1P(1) | 捕获使能 / 极性（0=上升沿） |
| `TIM3->DIER` | CC1IE(1) | 捕获中断 |
| `TIM3->SR` | CC1IF(1) | 捕获标志 |
| `TIM3->CCR1` | — | 锁存到的 CNT 值（只读） |

## 常见坑

- **忘了把 PA6 配成输入**（写成输出就测不到）
- **没处理计数器回绕**：`period = (t2 − t1) mod 65536`
- **ARR 设太小**：建议设 `0xFFFF`，让回绕只由 UIF 记录
- 没共地 → 测出一堆乱值

## 进阶

A) **PWM 输入模式**：把 TI1 同时接到 IC1 和 IC2，一次测出**周期 + 占空比**
B) 改 TIM2 的 ARR 换频率，看 LED 是否还能正确判定
C) 去测一个"外部"信号（比如学长板子上的某个方波）
