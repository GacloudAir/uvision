# L3 — 参数存 Flash + 看门狗 + 校验

## 目标

把时序参数存入 STM32 内部 Flash 末页，上电读回；挂 IWDG 看门狗防卡死；读回参数做范围校验+CRC，超范围回落默认。

## 硬件事实（F103C8，中容量）

- Flash 64KB，1KB/页，共 64 页；末页地址 `0x0800FC00`（页 63）
- 写单位 = 16 位（半字）；写前必须整页擦（擦后全 0xFFFF）
- 解锁钥匙：`KEYR` 依次写 `0x45670123`、`0xCDEF89AB`
- Flash 只能把 1 写 0，不能直接改 → 必须擦

## 任务清单

| 编号 | 任务 |
|---|---|
| 1 | `crc16`（校验结构体） |
| 2 | `flash_unlock` |
| 3 | `flash_erase_page`（等 BSY） |
| 4 | `flash_write_halfword`（16 位指针写） |
| 5 | `param_save`（算 crc→擦→写→锁） |
| 6 | `param_load`（读回+CRC+范围校验+回落默认） |
| 7 | `iwdg_init` |
| 8 | main 喂狗 |

## 寄存器速查

| 寄存器 | 位/作用 |
|---|---|
| `FLASH->KEYR` | 两次密钥解锁 |
| `FLASH->CR` | PER/STRT/PG/LOCK |
| `FLASH->SR` | BSY(bit0) 忙；EOP(bit5) 完成 |
| `IWDG->KR` | 0x5555 允许改 / 0xAAAA 喂 / 0xCCCC 启动 |
| `IWDG->PR/RLR` | 预分频 / 重载 |

## 关键领悟

> Flash 不是 RAM：写慢、有寿命、按页擦、按半字写。所以"存参数"的正确姿势是
> **算校验→解锁→擦整页→逐半字写→锁回**，且只在"参数真变了"时才写，别每帧都写。
> IWDG 是**独立**时钟驱动的看门狗，主频崩了它照样计时——这是"系统最后一道保险"。

## 验证方法

| 验证点 | 方法 | 期望 |
|---|---|---|
| 掉电保持 | 设参数→保存→断电→上电 | 读回一致 |
| 非法回落 | 手动改 Flash 一字节破坏 CRC | 上电回落默认，不崩 |
| 看门狗 | 故意死循环不喂狗 | 板子自动复位 |
